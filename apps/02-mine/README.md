# 02 · Mine!?

Vidéos, musique, sous-titres ou miniatures depuis YouTube et plus de mille autres sites, grâce à [yt-dlp](https://github.com/yt-dlp/yt-dlp).

- Page Apphéro : une vitrine avec la vidéo de présentation (pas de démo publique)
- Code et installation (Proxmox VE, Docker, app de bureau) : https://github.com/Naod6473/Mine-

Ce dossier ne contient que la page de présentation de l'app sur Apphéro ; l'app elle-même vit dans son propre dépôt.
